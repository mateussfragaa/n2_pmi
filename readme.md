# 🏷️ Cupom Maníacos

O **Cupom Maníacos** é uma ideia de projeto desenvolvida para a disciplina de Projeto Multigerador de Ideias (PMI). A proposta consiste em criar um site que ajude os consumidores a encontrar melhores oportunidades de compra, reunindo conceitos de acompanhamento de preços, cupons de desconto e identificação de ofertas.

## 💡 Sobre o projeto

A ideia surgiu da dificuldade de acompanhar os preços de produtos desejados e encontrar boas ofertas em meio a tantas promoções divulgadas em diferentes plataformas.

O Cupom Maníacos propõe uma experiência mais organizada, permitindo que o consumidor acompanhe produtos de seu interesse, estabeleça um preço-alvo e identifique oportunidades de compra.

## 🎯 Objetivos

- Facilitar a busca por ofertas e cupons de desconto.
- Permitir o acompanhamento de preços de produtos desejados.
- Ajudar o consumidor a identificar o momento mais adequado para comprar.
- Facilitar a comparação de preços, considerando também o frete.
- Tornar a busca por boas oportunidades mais simples e direcionada.

## ✨ Funcionalidades propostas

As principais funcionalidades planejadas para o projeto são:

- **Radar de preços:** acompanhamento dos preços de produtos desejados.
- **Preço-alvo:** definição de um valor que o consumidor pretende pagar.
- **Alertas de oportunidades:** possibilidade de avisar o usuário quando um produto atingir o preço desejado.
- **Cupons de desconto:** centralização de oportunidades e cupons.
- **Comparação de preços:** auxílio na identificação de melhores condições de compra, incluindo o frete.

Essas funcionalidades fazem parte da proposta do projeto e poderão ser desenvolvidas ao longo dos próximos semestres.

## 🖥️ Landing page

O projeto conta com uma landing page para apresentar a ideia, o problema identificado, a solução proposta e seus principais diferenciais.

A página foi desenvolvida utilizando:

- HTML5
- CSS3
- JavaScript puro

A interface possui design responsivo, efeitos visuais com glassmorphism e alternância entre temas claro e escuro.

## 🚀 Como executar

Para visualizar a landing page localmente:

1. Clone o repositório:

   ```bash
   git clone https://github.com/mateussfragaa/n2_pmi
   ```

2. Entre na pasta do projeto:

   ```bash
   cd N1_PMI
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências para executar a versão estática da página, desde que os arquivos e recursos utilizados estejam disponíveis localmente ou por meio de seus respectivos links externos.
